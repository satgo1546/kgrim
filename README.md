kgrim
=====

Grab images from KWin Wayland compositor. A drop-in replacement for [grim](https://gitlab.freedesktop.org/emersion/grim) on KDE Plasma.

## Install

Requires Qt6.

```sh
cmake -B build
cmake --build build
cmake --install build
```
